# Path Structure Material Provenance

The Path Network v2 bridge families use the following vendored 1K texture sets.
All files are unmodified JPG downloads from Poly Haven. Poly Haven publishes its
assets under CC0; attribution is not legally required, but OmniForge records it
for production traceability.

Runtime use:

- `wood_planks_grey` — timber decks, trestles, rails, and rope-bridge wood.
- `castle_wall_slates` — stone arches, masonry causeways, retaining walls, and tunnels.
- `gravel_embedded_concrete` — concrete decks, abutments, footings, piers, and caps.
- `metal_plate_02` — steel girders, cross-girders, braces, and rails.
